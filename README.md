# Blender3d - Modern House BIM / BOQ Workflow

Open-source teaching and prototyping workflow for a **10 m x 10 m single-storey Modern Box House**.

## Planned outputs

- Editable Blender model (`.blend`)
- Web/SketchUp-friendly 3D model (`.glb` / `.obj`)
- IFC concept model
- BOQ quantity schedule (`.csv`)
- Interactive Three.js viewer
- GitHub Actions build workflow

> Educational / concept workflow only. Structural dimensions and quantities must be verified by qualified engineers before construction or tender use.
